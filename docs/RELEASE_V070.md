# ClimateTest Manager v0.7.0

Versão focada na experiência de uso do aplicativo Windows.

- o ClimateTest Manager abre em uma janela própria do Windows, sem Chrome/Edge e sem barra de endereço;
- o servidor central continua rodando invisível em segundo plano;
- a transição de abertura usa a identidade visual do ClimateTest Manager;
- o cliente exibe diagnóstico amigável quando o servidor central está indisponível;
- a opção **Manter conectado neste computador por 30 dias** volta a aparecer no login;
- a sessão lembrada é armazenada no dispositivo cliente, e não no arquivo compartilhado do servidor;
- favicon e animação de carregamento do acesso web de diagnóstico também passam a usar o logo do sistema;
- Flet atualizado para 0.86.4, incluindo correções relacionadas a serviços em `FletApp` incorporado.

O banco de dados e os backups existentes são preservados durante a atualização.
